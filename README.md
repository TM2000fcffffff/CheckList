# 그거 언제 했더라?

이불 빨래, 칫솔 교체, 머리 자르기처럼 가끔 하는 일을 **마지막으로 한 날부터 며칠 지났는지** 보여 주는 기록장입니다.

## 기능
- 버튼 한 번으로 오늘 한 일 기록, 5초 안에 되돌리기
- 권장 주기 대비 상태 표시 (여유 / 곧 할 때 / 지남)
- 급한 순 · 오래된 순 · 이름순 정렬
- 월별 달력 보기, 날짜를 골라 지난 기록 추가·삭제
- 모든 데이터는 브라우저(`localStorage`)에만 저장

## 실행
빌드 과정 없이 `index.html`을 웹 서버로 열면 됩니다. (HTML/CSS/JavaScript만 사용)
