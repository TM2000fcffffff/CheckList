# "그거 언제 했더라?" 사용법

> 이 문서는 사용자 도움말 챗봇의 기준 자료입니다. 챗봇은 이 문서에 있는 내용만 근거로 답하고, 없는 기능은 "아직 없는 기능"이라고 안내합니다.
> 화면 문구(버튼 이름 등)는 실제 화면과 똑같이 적었습니다. 기능을 바꾸면 이 문서도 함께 고칩니다.
> 기준일: 2026-10-22

---

## 1. 서비스 소개

- **이름**: 그거 언제 했더라?
- **주소**: https://checklist-five-pi.vercel.app/
- **하는 일**: 이불 빨래, 칫솔 교체, 머리 자르기처럼 가끔 하는 일을 **마지막으로 한 날부터 며칠 지났는지** 보여 주는 웹 기록장입니다.
- **가격**: 무료입니다. 앱 설치나 회원 가입 없이 휴대폰·PC 브라우저에서 바로 씁니다.
- **로그인**: 기본 기능은 로그인 없이 쓸 수 있습니다. 여러 기기 동기화와 그룹(집안일 룰렛) 기능만 Google 로그인이 필요합니다.
- **언어**: 한국어

### 화면 구성

맨 위에 제목, 동기화 상태, 로그인 버튼(또는 내 이름과 [로그아웃])이 있고, 그 아래에 세 개의 탭과 정렬 메뉴가 있습니다.

| 탭 | 내용 |
|---|---|
| 목록 | 내 항목 카드 목록. 기본 화면 |
| 달력 | 월별 달력에서 한 날과 다음 예정일 확인 |
| 그룹 | 가족·룸메이트와 함께 쓰는 집안일 목록과 룰렛 |

오른쪽 아래의 둥근 **[+]** 버튼으로 항목을 추가합니다. (화면을 아래로 내리면 잠시 숨었다가 위로 올리면 다시 나타납니다.)

## 2. 항목 추가하기

1. 오른쪽 아래 **[+]** 버튼을 누릅니다.
2. **이름**을 입력합니다(필수, 30자까지). 예: 이불 빨래
3. 이름 왼쪽의 **아이콘**을 눌러 바꿀 수 있습니다(선택).
4. **주기**를 입력합니다(선택). 예: 14일마다
5. **마지막으로 언제 했어요?** 를 고릅니다(선택).
6. **[저장]** 을 누릅니다.

### 입력을 도와주는 기능
- **아이콘 자동 추천**: 이름을 입력하면 이름에 맞는 아이콘이 자동으로 골라집니다. (예: "화분" → 🌱, "칫솔" → 🦷, "빨래" → 🧺) 아이콘을 직접 고르면 그 뒤로는 자동으로 바뀌지 않습니다.
- **주기 빠른 선택**: [1주] [2주] [1달] [3달] [6달] [1년] 버튼으로 바로 입력합니다. (각각 7·14·30·90·180·365일)
- **마지막으로 한 날 빠른 선택**: [오늘] [어제] [1주 전] [2주 전] [1달 전] [모름] 중에서 고르거나, 아래 날짜 칸에서 직접 고릅니다. [모름]을 고르면 기록 없이 항목만 만들어집니다.

### 입력 규칙
- 주기는 **1~3650일** 사이 숫자입니다. 비워 두면 주기 없는 항목이 됩니다.
- 마지막으로 한 날은 **오늘이나 지난 날짜**만 됩니다. (미래 날짜 불가)
- 창을 닫으려면 오른쪽 위 **✕**, **[취소]**, 또는 창 바깥 어두운 부분을 누릅니다.

### 처음 쓸 때 (추천 항목)
항목이 하나도 없으면 "아직 항목이 없어요"와 함께 추천 항목이 보입니다. 추천을 누르면 이름·아이콘·주기가 미리 채워진 추가 창이 열리고, 확인 후 [저장]하면 추가됩니다. 항목이 3개보다 적을 때는 "이런 것도 추가해 보세요"로 남은 추천을 계속 보여 줍니다.

| 추천 항목 | 아이콘 | 주기 |
|---|---|---|
| 이불 빨래 | 🛏️ | 14일 |
| 화장실 청소 | 🚽 | 7일 |
| 냉장고 청소 | 🧊 | 30일 |
| 칫솔 교체 | 🦷 | 90일 |
| 정수기 필터 교체 | 💧 | 90일 |
| 머리 자르기 | 💇 | 30일 |
| 손톱 깎기 | 💅 | 7일 |
| 치과 검진 | 🏥 | 180일 |
| 화분 물 주기 | 🌱 | 7일 |
| 부모님께 전화 | 📞 | 7일 |

## 3. 아이콘 바꾸기

- 항목 창에서 이름 왼쪽 아이콘을 누르면 아이콘 목록이 펼쳐집니다. 원하는 이모지를 누르면 됩니다.
- **[📷 이미지 올리기]** 로 휴대폰 사진이나 이미지 파일을 아이콘으로 쓸 수 있습니다. 가운데를 정사각형으로 잘라 작게 줄여 저장합니다.
  - 이미지 파일만 올릴 수 있고, 15MB 이하여야 합니다.
- 아이콘을 글자로 직접 입력하는 칸은 없습니다. 목록에서 고르거나 이미지를 올려야 합니다.
- Windows 10 등 일부 기기에서는 최신 이모지가 네모(□)로 보일 수 있습니다. 그럴 땐 다른 아이콘을 고르거나 이미지를 올려 주세요.

## 4. 기록하기 — [했어요]

- 그 일을 했으면 카드 오른쪽 **[했어요]** 를 누릅니다. 오늘 날짜로 기록되고 "✅ (이름) 기록했어요" 알림이 뜹니다.
- **잘못 눌렀다면** 알림의 **[취소]** 를 5초 안에 누르면 되돌아갑니다.
- 같은 항목을 하루에 두 번 누르면 "오늘 이미 기록했어요"라고 알려 주고 다시 기록하지 않습니다.
- 지난 날짜로 기록하려면 → 5장(지난 기록) 또는 7장(달력)을 보세요.

---

## 5. 지난 기록 보기·고치기

카드(이름 부분)를 누르면 항목 창이 열리고, 아래에 **기록** 칸이 보입니다.

- 요약: "N번 기록 · 마지막 23일 전 · 평균 18일마다 했어요" (기록이 2개 이상일 때 평균 주기 표시)
- 지난 날짜 목록: 최근 5개가 보이고, **[N개 더 보기]** 로 나머지를 봅니다.
- **날짜 추가**: 날짜 칸에서 날짜를 고르고 **[날짜 추가]**. 미래 날짜나 이미 있는 날짜는 추가되지 않습니다.
- **날짜 지우기**: 각 날짜 오른쪽 **✕**.
- 추가·삭제는 **[저장]** 을 눌러야 반영됩니다. [취소]하면 바뀌지 않습니다.
- 같은 창에서 이름·아이콘·주기도 고칠 수 있습니다.

## 6. 경과일과 상태 색상

### 경과일 표시
| 마지막으로 한 날 | 표시 |
|---|---|
| 오늘 | 오늘 |
| 어제 | 어제 |
| 2일 이상 전 | N일 전 |
| 기록 없음 | 아직 기록 없음 |

날짜는 기기에 설정된 현지 날짜 기준으로, 시간은 따지지 않고 날짜 단위로 셉니다.

### 상태 색상 (주기가 있을 때)
`지난 일수 ÷ 주기` 비율로 정합니다.

| 비율 | 배지 | 색 | 예 (주기 14일) |
|---|---|---|---|
| 70% 미만 | 여유 | 초록 | 0~9일 |
| 70% 이상 100% 미만 | 곧 할 때 | 노랑 | 10~13일 |
| 100% 이상 | 지남 | 빨강 | 14일~ |

- 카드에는 "11일 전 · 3일 남음", "14일 전 · 오늘 할 차례", "16일 전 · 2일 지남"처럼 함께 표시됩니다.
- 카드 아래 막대는 주기 대비 얼마나 지났는지 보여 줍니다.
- **[했어요]** 버튼은 평소 옅은 색이고, 주기를 넘긴(지남) 항목에서만 진하게 표시됩니다.
- 주기가 없는 항목은 색 없이 회색으로 경과일만 보여 줍니다.
- 색만으로 구분하지 않도록 "여유/곧 할 때/지남" 글자도 함께 표시합니다.

## 7. 정렬

맨 위 정렬 메뉴에서 고릅니다. 고른 정렬은 기억됩니다.

| 정렬 | 순서 |
|---|---|
| 급한 순 (기본) | ① 주기 있는 항목을 비율 높은 순 → ② 주기 없는 항목을 오래된 순 → ③ 기록 없는 항목 |
| 오래된 순 | 마지막으로 한 날이 오래된 항목부터 |
| 이름순 | 가나다순 |

## 8. 항목 삭제

1. 카드를 눌러 항목 창을 엽니다.
2. **[이 항목 삭제]** 를 누르면 "한 번 더 누르면 삭제돼요"로 바뀝니다.
3. 3초 안에 한 번 더 누르면 삭제됩니다.
4. 실수로 지웠다면 알림의 **[취소]** 를 5초 안에 누르면 되돌아갑니다.

## 9. 달력 보기

위쪽 **[달력]** 탭을 누릅니다.

- **‹ ›** 로 이전·다음 달, **[오늘]** 로 이번 달로 돌아옵니다.
- 제목 아래에 "이번 달 기록 N회 · 예정 N개"가 보입니다.
- 항목 필터 메뉴에서 **전체 항목** 또는 특정 항목만 골라 볼 수 있습니다.

### 달력 표시
| 표시 | 뜻 |
|---|---|
| ✓ 아이콘 | 그날 한 일 |
| 점선 테두리 아이콘 | 다음 예정일 (마지막으로 한 날 + 주기) |
| 빨간 테두리 아이콘 | 예정일이 이미 지남 |

- 예정일은 항목마다 **다음 한 번**만 표시합니다. 주기나 기록이 없는 항목은 예정일이 없습니다.

### 날짜를 눌렀을 때
- 아래에 그날 정보가 나옵니다. 예정이 있으면 "📅 예정 · N일 남음" 또는 "⚠️ 예정 지남 · N일 지남"으로 안내합니다.
- 항목 칩을 누르면 **그날 기록을 추가**하고, 이미 기록된 칩을 누르면 **그날 기록을 지웁니다**.
- 미래 날짜에는 기록할 수 없습니다.

## 10. 로그인과 동기화

### 로그인하지 않으면
- 기록은 **지금 쓰는 기기의 브라우저에만** 저장됩니다.
- 목록 아래에 "📱 지금은 이 기기에만 저장돼요…" 안내가 보입니다.
- 브라우저 데이터(쿠키·사이트 데이터)를 지우면 기록이 사라지니 로그인하거나 백업해 두세요.
- 시크릿 모드 등 저장이 막힌 브라우저에서는 "기록이 저장되지 않을 수 있어요" 경고가 뜹니다.

### Google로 로그인하면
- 맨 위 **[Google로 로그인]** 을 누릅니다. Google 계정으로만 로그인할 수 있습니다.
- 기록이 클라우드에 저장되어, 같은 Google 계정으로 로그인한 휴대폰·PC 등 모든 기기에서 같은 기록을 봅니다.
- 처음 로그인하면 그 기기에 있던 기록이 계정으로 합쳐집니다.
- 화면은 바로 바뀌고 저장은 뒤에서 처리됩니다. 다른 기기에서 바꾼 내용은 앱으로 다시 돌아오거나 인터넷이 다시 연결될 때 받아 옵니다.
- 인터넷이 끊겨도 기기에 저장해 두었다가 다시 연결되면 보냅니다.

### 동기화 상태 표시 (제목 아래)
| 표시 | 뜻 |
|---|---|
| ☁️ 연결 중… | 로그인 정보를 확인하는 중 |
| ☁️ 동기화 중… | 클라우드와 주고받는 중 |
| ☁️ 동기화됨 | 클라우드에 저장 완료 |
| 📱 이 기기에만 저장 중 | 로그인하지 않음 |
| 📴 오프라인 · 기기에 저장됨 | 인터넷 끊김. 연결되면 자동으로 보냄 |
| ⚠️ 동기화 실패 · 기기에 저장됨 | 서버 저장 실패. 기록은 기기에 남아 있음 |

### 로그아웃
- 맨 위 **[로그아웃]** 을 누릅니다.
- 다른 사람이 같은 기기를 써도 기록이 섞이지 않도록 **이 기기에서는 기록을 지웁니다.** 클라우드에는 그대로 남아 있어서, 다시 로그인하면 돌아옵니다.

### 로그인이 안 될 때
- 현재 Google 로그인은 시험 운영 중이라 **등록된 테스트 사용자만** 로그인할 수 있습니다. 로그인이 막히면 운영자에게 계정 등록을 요청해 주세요.
- 카카오톡 등 일부 앱 안의 브라우저에서는 Google 로그인이 막힐 수 있습니다. Chrome이나 Safari로 열어 주세요.

## 11. 백업 내보내기·가져오기

목록 아래에 있습니다. 로그인하지 않은 사용자에게 특히 권장합니다.

- **[⬇️ 백업 내보내기]**: 모든 항목과 기록을 `그거언제했더라_백업_날짜.json` 파일로 저장합니다.
- **[⬆️ 백업 가져오기]**: 백업 파일을 골라 복원합니다.
  - 이미 있는 같은 항목은 기록 날짜를 **합치고**, 없는 항목은 **새로 추가**합니다. 기존 기록이 지워지지 않습니다.
  - "새 항목 N개, 합친 항목 N개를 가져왔어요" 알림의 **[취소]** 로 5초 안에 되돌릴 수 있습니다.
  - 5MB 이하 JSON 파일만 가져올 수 있습니다.
- 다른 기기로 옮길 때: 이전 기기에서 내보내기 → 파일을 새 기기로 옮기기 → 새 기기에서 가져오기. (또는 두 기기 모두 같은 Google 계정으로 로그인)

## 12. 홈 화면에 추가 (앱처럼 쓰기)

- 설치를 지원하는 브라우저(안드로이드 Chrome·삼성 인터넷, PC Chrome·Edge 등)에서는 목록 아래 **[📲 홈 화면에 추가]** 버튼이 보입니다. 누르면 앱처럼 설치됩니다.
- 버튼이 안 보이면 브라우저 메뉴에서 직접 추가합니다.
  - iPhone Safari: 아래 공유 버튼 → **홈 화면에 추가**
  - 안드로이드 Chrome: 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 앱 설치)
- 설치하면 인터넷이 끊겨도 마지막으로 열었던 화면이 열립니다.

## 13. 그룹 — 가족·룸메이트와 집안일 나누기

그룹 기능은 **Google 로그인**이 필요합니다. 로그인하지 않으면 [그룹] 탭에 로그인 안내가 보입니다.

### 그룹 만들기
1. **[그룹]** 탭 → **새 그룹 만들기**에 그룹 이름(예: 우리 집)을 입력하고 **[만들기]**.
2. 만든 사람이 **그룹장**이 됩니다.
3. 여러 그룹에 속할 수 있고, 그룹 화면 위 메뉴에서 그룹을 바꿉니다. 메뉴의 **➕ 새 그룹 만들기 / 참여** 로 그룹을 더 만들거나 참여합니다.

### 초대하기
- **[초대하기]** 를 누르면 휴대폰 공유 창이 열리거나, 초대 링크가 복사됩니다. 카카오톡 등으로 보내면 됩니다.
- 그룹 화면에 보이는 **초대 코드**(10자리)를 직접 알려 줘도 됩니다.

### 참여하기
- **초대 링크**로 들어오면 로그인 후 "'그룹 이름' 그룹에 참여할까요?" 확인 카드가 나옵니다. 몇 명이 쓰고 있는지 보여 주며, **[참여하기]** 를 눌러야 가입됩니다. ([괜찮아요]를 누르면 가입하지 않음)
- **초대 코드**로는 [그룹] 탭 → **초대 코드로 참여**에 코드를 넣고 **[참여]**.
- 참여하면 그룹원에게 내 **Google 이름과 프로필 사진**이 보입니다.
- "초대 코드를 찾을 수 없어요"가 나오면 코드가 틀렸거나 그룹장이 코드를 바꾼 것입니다. 새 링크를 받아 주세요.
- 틀린 코드를 짧은 시간에 여러 번(15분에 10번) 넣으면 잠시 참여가 제한됩니다. 잠시 뒤 다시 시도하세요.

### 그룹 집안일
- 그룹마다 **공유 집안일 목록**이 따로 있습니다. 내 개인 항목과는 별개입니다.
- 아래 입력 칸에서 아이콘·이름·주기(일)를 넣고 **[추가]**. 그룹원 누구나 추가할 수 있습니다.
- 카드의 **[했어요]** 를 누르면 **누가 했는지**와 함께 기록되고, 카드에 "3일 전 · 2일 남음 · 홍길동"처럼 마지막으로 한 사람이 표시됩니다.
- 상태 색상(여유·곧 할 때·지남)은 개인 항목과 같은 기준입니다.
- 카드의 **아이콘을 누르면** 아이콘을 바꿀 수 있습니다(이모지 또는 이미지).
- **🗑** 를 누르면 "삭제?"로 바뀌고, 3초 안에 한 번 더 누르면 삭제됩니다. (그룹 집안일 삭제는 되돌릴 수 없습니다.)

### 🎰 누가 할까? 룰렛
1. 룰렛 칸에서 집안일을 고르고 **[돌리기]**.
2. 그룹원 이름이 빠르게 돌다가 한 명에서 멈춥니다.
3. 결과는 **그룹원 모두의 화면**에 같은 애니메이션으로 실시간 표시됩니다.
- 당첨자는 **서버가 무작위로** 뽑기 때문에 아무도 조작할 수 없습니다.
- **최근 결과** 8개가 "날짜 시간 · 집안일 → 🏆 이름"으로 보입니다.
  - 내가 당첨된 결과에는 **[완료했어요]** 버튼이 있고, 누르면 그 집안일이 내 이름으로 기록됩니다.
  - 다른 사람 차례는 "⏳ 대기 중", 끝난 것은 "✅ 완료"로 표시됩니다.
- 그룹 집안일이 없으면 룰렛을 돌릴 수 없습니다. 먼저 집안일을 추가하세요.

### 그룹장만 할 수 있는 일
- **그룹원 내보내기**: 그룹원 이름 옆 **✕** 를 누르면 "내보내기?"로 바뀌고, 한 번 더 누르면 내보냅니다.
- **초대 코드 바꾸기**: 초대 코드 옆 **[코드 바꾸기]** 를 두 번 누르면 새 코드가 만들어집니다. **예전 링크와 코드는 더 이상 쓸 수 없습니다.** 초대 링크가 원치 않는 사람에게 퍼졌을 때 씁니다.

### 그룹 나가기
- 맨 아래 **[그룹 나가기]** 를 누르면 "한 번 더 누르면 나가요"로 바뀌고, 한 번 더 누르면 나갑니다.
- 다시 들어오려면 초대 코드나 링크가 필요합니다.

## 14. 개인정보와 보안

- 로그인하지 않으면 기록은 기기 브라우저에만 있고 외부로 보내지 않습니다.
- 로그인하면 기록은 클라우드(Supabase)에 저장되며, **본인만** 자기 기록을 볼 수 있습니다.
- 그룹에서는 같은 그룹원끼리만 그룹 집안일·기록·룰렛 결과와 서로의 Google 이름·프로필 사진을 볼 수 있습니다. 개인 항목은 그룹원에게 보이지 않습니다.
- 그룹원 표시 이름은 Google 계정 정보를 그대로 씁니다.

## 15. 자주 묻는 질문

**Q. 사용료가 있나요?**
무료입니다. 설치나 회원 가입 없이 쓸 수 있고, 동기화와 그룹 기능만 Google 로그인이 필요합니다.

**Q. [했어요]를 잘못 눌렀어요.**
알림의 [취소]를 5초 안에 누르세요. 시간이 지났다면 카드를 눌러 기록 목록에서 오늘 날짜의 ✕를 누르고 [저장]하거나, 달력에서 오늘 날짜를 눌러 그 항목 칩을 다시 누르면 지워집니다.

**Q. 어제 했는데 오늘 기록하는 걸 깜빡했어요.**
카드를 눌러 기록 칸에서 어제 날짜를 [날짜 추가] → [저장]하세요. 달력 탭에서 어제 날짜를 누르고 항목 칩을 눌러도 됩니다.

**Q. 하루에 두 번 기록할 수 있나요?**
아니요. 기록은 날짜 단위라 같은 날은 한 번만 기록됩니다.

**Q. 알림(푸시)을 받을 수 있나요?**
아직 없는 기능입니다. 앱을 열어 급한 순 정렬이나 달력의 예정일로 확인해 주세요.

**Q. 분류(태그)나 검색, 메모 기능이 있나요?**
아직 없는 기능입니다.

**Q. 칫솔이나 이불은 얼마나 자주 바꾸거나 빨아야 하나요?**
일반적으로 칫솔은 약 3개월(90일)마다 교체하고, 이불은 1~2주(7~14일)마다 빨래하기를 권합니다.

**Q. 휴대폰을 바꿨는데 기록을 옮기고 싶어요.**
두 기기 모두 같은 Google 계정으로 로그인하면 자동으로 옮겨집니다. 로그인하지 않았다면 이전 기기에서 [백업 내보내기] 후 새 기기에서 [백업 가져오기]를 하세요.

**Q. 기록이 사라졌어요.**
- 로그인했었다면 다시 로그인하면 클라우드의 기록이 돌아옵니다. (로그아웃하면 기기에서만 지워짐)
- 로그인하지 않았다면 브라우저 데이터를 지웠거나 시크릿 모드였을 수 있습니다. 이 경우 백업 파일이 있어야 복원할 수 있습니다.
- 다른 브라우저(예: Chrome ↔ 삼성 인터넷)나 앱 안 브라우저로 열었는지도 확인해 주세요. 브라우저마다 저장 공간이 따로입니다.

**Q. PC와 휴대폰 기록이 다르게 보여요.**
두 기기가 같은 Google 계정으로 로그인되어 있는지, 제목 아래 상태가 "☁️ 동기화됨"인지 확인하세요. 앱을 다른 탭으로 갔다가 돌아오면 최신 기록을 다시 받아 옵니다.

**Q. "⚠️ 동기화 실패"가 떠요.**
기록은 기기에 안전하게 저장되어 있습니다. 인터넷 연결을 확인하고 잠시 뒤 앱을 다시 열면 다시 시도합니다.

**Q. 주기를 정하지 않아도 되나요?**
네. 주기가 없으면 색 없이 "N일 전"만 표시되고, 급한 순 정렬에서 주기 있는 항목 뒤에 옵니다. 달력 예정일도 표시되지 않습니다.

**Q. 그룹 집안일이 내 목록에도 보이나요?**
아니요. 그룹 집안일은 [그룹] 탭에서만 보이고, 내 개인 항목과 따로 관리됩니다.

**Q. 룰렛을 다시 돌리면 다른 사람이 나올 수 있나요?**
네. 돌릴 때마다 서버가 그룹원 중에서 새로 무작위로 뽑습니다. 모든 결과는 최근 결과 목록에 남아 그룹원 모두가 볼 수 있습니다.

**Q. 그룹장이 나가면 어떻게 되나요?**
이 문서에서 다루지 않는 내용입니다. 운영자에게 문의해 주세요.

**Q. 다크 모드가 있나요?**
휴대폰·PC의 시스템 설정(다크 모드)을 따라 자동으로 바뀝니다. 앱 안에서 따로 바꾸는 설정은 없습니다.
